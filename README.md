## ⚙️ Setup — Google Sheets (5 minutos)

### Paso 1 — Crear el Google Sheet

1. Andá a **[sheets.new](https://sheets.new)** y creá una nueva hoja
2. Nombrala `Prode Mundial 2026`
3. Creá **3 pestañas** con estos nombres exactos: `players` · `predictions` · `results`

### Paso 2 — Agregar el script

1. En el Sheet: **Extensiones → Apps Script**
2. Borrá todo el código existente
3. Copiá y pegá el contenido de [`google-apps-script/Code.gs`](google-apps-script/Code.gs)
4. Guardá con **Ctrl+S**

### Paso 3 — Deployar como Web App

1. Click en **Implementar → Nueva implementación**
2. Tipo: **Aplicación web** · Ejecutar como: **Yo** · Acceso: **Cualquier persona**
3. Click **Implementar** → copiá la URL

### Paso 4 — Conectar la app

1. Abrí el prode: https://jpfiorilli.github.io/mundial-prode-2026
2. Pegá la URL del script cuando te la pida
3. ¡Compartí el link con tus amigos!

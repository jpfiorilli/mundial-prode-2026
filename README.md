# 🏆 Prode — Mundial FIFA 2026

Jugá el prode del Mundial con tus amigos.

🔗 **[Abrir el Prode](https://jpfiorilli.github.io/mundial-prode-2026)**

## Cómo funciona

- Cada jugador entra con su nombre
- Predice el marcador de cada partido antes de que empiece
- Los resultados reales se cargan en la misma pantalla
- Los puntos se calculan automáticamente

## Puntaje

| Pts | Resultado |
|-----|-----------|
| 3 | Marcador exacto |
| 1 | Ganador correcto |
| 0 | Resultado incorrecto |

## Tecnología

- App estática en HTML/CSS/JS — sin servidor
- Predicciones guardadas en localStorage (por dispositivo)
- Desplegada en GitHub Pages
